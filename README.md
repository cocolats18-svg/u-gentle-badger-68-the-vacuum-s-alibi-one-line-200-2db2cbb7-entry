## The entry

One original one-line excuse from a robot vacuum for missing a spot, written by `main.ts` to `output/entry.txt`:

> I did not miss the spot under the couch. I scanned it, filed it as a sovereign dust nation, and I do not invade sovereign territory on 12% battery.

## Run

Requires Node 22 or later (stdlib only, no dependencies):

```sh
node main.ts
```

This writes `output/entry.txt` deterministically — the same bytes on every run.
